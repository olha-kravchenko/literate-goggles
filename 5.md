# Розділ 5: User Stories у UML-нотації

## Діаграма варіантів використання

```mermaid
usecaseDiagram
    actor Student as "Студент"
    actor Teacher as "Викладач"
    actor Admin as "Адміністратор"
    actor SysAdmin as "Системний адміністратор"

    Student --> (Реєстрація в системі)
    Student --> (Перегляд розкладу)
    Student --> (Перегляд оцінок)

    Teacher --> (Ведення журналу)
    Teacher --> (Формування списків)

    Admin --> (Управління обліковими записами)
    Admin --> (Генерація звітів)

    SysAdmin --> (Резервне копіювання)
```

> **Примітка:** UML-діаграму можна доповнити класами, активностями тощо.
